Process File Requests

Offsets count CPU time already executed by the selected process, not global simulation time. One command can be configured at each offset. Commands are parsed and executed by the simulator.

Supported commands: MKDIR /docs, CREATE /docs/notes.txt, WRITE /docs/notes.txt "Hello OS", READ /docs/notes.txt, DELETE /docs/notes.txt, RMDIR /docs, LS /, CD /docs, PWD, STAT /docs. Operation errors are recorded in the activity log; each process has its own working directory in the shared file tree.

Append, file handles, permissions, and storage commands
  • APPEND /docs/notes.txt " more text" adds content.
  • OPEN /docs/notes.txt r opens an existing file and returns a handle in the activity log. Modes: r, w, a, r+, w+, a+. Modes beginning with w truncate the file.
  • HANDLE_READ 1, HANDLE_WRITE 1 "text", and CLOSE 1 use the returned handle. The number 1 is an example; handles belong to the current simulation. Requests use literal handle numbers, without automatic substitution. Reset preserves handle state; use a fresh simulation when a script relies on numbering starting at 1.
  • CHMOD /docs/notes.txt r-- changes the shared permission mask. The creating process PID is the owner; only that owner can change permissions through process requests.
  • STORAGE returns the total UTF-8 bytes of file contents. STAT /docs/notes.txt returns metadata, including permissions.
